Cursor lansira Origin — AI-native code hosting platformu koja izaziva GitHub na svom terenu

Godinama je GitHub bio default izbor za hosting koda. Ali nedavna serija outage-a — 257 u zadnjih godinu dana po LeadDev analizi, svenskodnevni globalni outage sa gotovo 20% error rate-om — stvorila je prostor. Cursor, AI startup koji je zvanično postao dio SpaceX-a, iskoristio je priliku i lansirao Origin: code hosting platformu napravljenu za AI-first development.

Što je Origin i zašto sada

Origin radi sve što developeri očekuju od GitHuba: kolaborativno rad na codebase-ovima, browsiranje i editing, pull requestovi, repozitoriji. Ali dizajniran je od nule za "agent-native" funkcionalnosti koje će uskoro doći. Cursor tvrdi da je to "prirodan sljedeći korak" za njihov AI Code Editor.

Ključna razlika: Origin ne zahtijeva migraciju sa GitHuba. Repozitoriji mogu sedjeti s jedne i druge strane. "Vaši GitHub repos mogu sjediti pored onih koje hosta Cursor. Povežite GitHub sa Cursorom, izaberite org, videćete repozitorije za sync. Izaberite jedan i Cursor ga povuče."

Kontekst: GitHub-ovi problemi su strukturni

  • 257 outage-a u zadnjih 12 mjeseci (LeadDev)
  • Globalni outage 18. avgusta — 6+ sati, ~20% error rate worldwide
  • Ranije ove godine: GitHub objavio nove mjere za "addressing availability issues"
  • "Vidljiv egzodus high-profile usera" (LeadDev, Charles Humble)
  • 180M developera na GitHubu (oktobar 2025.) — Microsoft vlasnik od 2012.

Cursorova akvizicija od strane SpaceX-a (završena 15. avgusta) dodaje dimenziju: Elon Musk-ov interes za developer tooling i AI infrastructure. SpaceX koristi Cursor unutrašnje; sada posjeduju platformu.

Agent-native znači šta, točno?

Cursor nije još objavio detalje, ali "agent-native features coming soon" implicira:

  • AI agenti koji mogu čitati, pisati, testirati, deploy-at direktno unutar platforme
  • Automatsko generiranje PR-ova sa kontekstom iz issue-a
  • AI code review koji ide šalih linija koda — razumije arhitekturu, sigurnost, performance
  • Integracija sa Cursorovim AI Code Editorom (agent workflow)
  • "Wider app ecosystem" za širu podršku coding naporima unutar Origin

Zašto je to važno za enterprise development timove u regionu

Firme u BiH i regionu koje imaju development timove (ili outsource-e) suočavaju se s dva izazova:

  1. Produktivnost: AI coding assistants (Cursor, Copilot, Claude Code) drastično ubrzavaju pisanje koda. Ali bottleneck se pomjera: code review, CI/CD, debugging, deployment.
  2. Vendor lock-in i stabilnost: Ovisnost o jednom GitHub-u postaje rizik kad servis nije stabilan.

Origin nudi alternativu koja je dizajnirana za AI workflow, ne retrofit-ovana na nj. Kad agent-native features stignu, timovi koji su već na Origin-u bit će korak ispred.

BIXIE perspektiva: kako to utiče na naše klijente

Mi u BIXIE već implementiramo AI-enhanced development pipeline-ove za klijente. Origin nam daje:

  • Drugu opciju hostinga kad klijent ne želi ili ne može GitHub (compliance, cost, data residency)
  • Native integraciju sa Cursor editorom — naš tim koristi Cursor, sada imamo end-to-end AI stack
  • SpaceX backing — signal da platforma ima dugotrajnu podršku i resurse
  • Interoperabilnost — ne moramo migrirati sve odjednom, možemo piloti na jednom repozitoriju

Rizici i pitanja

  • GitHub ima 180M developera, network effect je ogroman
  • Agent-native features su i dalje "coming soon" — nema demo, nema docs
  • SpaceX vlasništvo: kako to utiče na neutralnost platforme? (SpaceX koristi, ali i prodaje konkurenciji?)
  • Pricing model nepoznat
  • Enterprise features (SAML, audit logs, compliance certifications) — jesu li spremne?

Što slijedi

Cursor je u "validation stage" — traže real tasks da benchmarkaju. Mi u BIXIE pratimo ovo Tesko. Za klijente koji razmišljaju o diversifikaciji code hostinga ili žele AI-first platformu, Origin postaje opcija za praćenje (i pilotiranje).

Jedno je sigurno: epocha "GitHub ili ništa" je gotova. AI mijenja ne samo kako pišemo kod, već i gdje ga držimo.
