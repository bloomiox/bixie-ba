Agent Plugins 1.0: novi standard koji čini AI agente prenosivim

5. Maj 2026 · BIXIE Team · 12 min čitanja

Danas je objavljen Agent Plugins 1.0 — otvoren, vendor-neutralan standard za pakovanje AI vještina (Agent Skills) i MCP servera u prenosive plugin pakete. Iza njega stoje Vercel, OpenAI, Microsoft, Cursor i Amazon. Jednom upakovano — radi na svim većim AI klijentima: ChatGPT/Codex, Cursor, GitHub Copilot, VS Code i Kiro.

Ovo nije još jedan framework. Ovo je pokušaj industrije da riješi problem koji je postao očigledan: svaki AI klijent ima svoj format za proširenja, pa se ista sposobnost mora pakovati iznova za svaki alat.

Šta standard tačno definiše

Agent Plugin je jednostavno direktorij s malim manifestom i fiksnim lokacijama:

  • plugin.json — manifest koji identificira verziju specifikacije i ime plugina;
  • skills/ — proceduralno znanje (SKILL.md + skripte + reference), u postojećem formatu Agent Skills;
  • mcp.json — konfiguracija MCP servera koji povezuje agenta s vašim sistemima u runtime-u;
  • namespace direktoriji — za klijent-specifična proširenja koja drugi klijenti jednostavno ignorišu.

Standard namjerno ne zadire u instalaciju, dozvole, distribuciju ni trust — to ostaje u rukama svakog klijenta. Interoperabilnost se gradi na malom, predvidljivom jezgru, a ne na pokušaju da svi klijenti budu isti.

Zašto je ovo strateški važno

Do sada, "prenosivost AI sposobnosti" je bila mantra bez standarda. Agent Plugins 1.0 daje format koji kompanije mogu koristiti odmah: razvojni tim upakuje svoje vještine jednom i nosi ih kroz ekosistem.

Za firme koje implementiraju AI agente — kao što mi radimo kroz BIXIE — ovo mijenja igru u tri aspekta:

  • Bez vendor lock-a: klijent koji danas koristi agente u jednom alatu može sutra preći u drugi bez ponovnog pakovanja. To je tačno ono što obećavamo našim klijentima — i sada postoji standard koji to i tehnički omogućava.
  • Ponovna upotreba: vještina napravljena za jednog klijenta (npr. agent za obradu faktura) može se standardizovati i ponuditi drugima, bez prepravljanja.
  • Konvergencija tržišta: kada veliki igrači zajedno grade otvoreni standard, to je signal da se ekosistem stabilizuje — dobra vijest za sve koji donose dugoročne odluke o AI arhitekturi.

Šta ne treba očekivati (još)

Verzija 1.0 svjesno pokriva samo Skills i MCP servere. Agenti, komande, hookovi i UI ekstenzije nemaju još zajedničke semantike — dolaze u kasnijim verzijama ako se pokaže potreba. Također, standard ne rješava otkrivanje plugina (katalozi) ni trust (potpisivanje, provjera izdavača) — to su zasebni slojevi koji se grade paralelno.

Naš pogled

Agent Plugins 1.0 je jedan od onih trenutaka kada industrija prestane improvizovati i počne graditi infrastrukturu. Za klijente koji žele AI agente "koji nisu zaključani" — ovo je dan kada je ta rečenica dobila tehničko uporište.
